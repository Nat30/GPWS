- English peer: [2026-11-20-app-extensions-design.md](2026-11-20-app-extensions-design.md)

## 1. 背景与目标

设备现状: 24 条 PCM 航空警示音宫格浏览/播放, 三键输入, 设置弹窗 5 行满配,
闲置熄屏/深睡。本次扩展新增 4 个功能 + 1 个入口底座, 全部复用现有架构资产
(stats 滚动列表版式 / modal 编辑模式 / 连播视觉跟随 / 深睡序列 / NVS 持久化),
新增纯逻辑模块延续 host 可测纪律(menu_ctl / quiz_ctl / scenes / boot 环形日志)。

量级预估: ~1300 行(不含测试), 分 5 批实现(见第 9 节)。

## 2. 主菜单(入口底座)

**menu_ctl.h 纯状态机**(~50 行 + host 测试): 状态 = {open, item}; 事件矩阵 =
UP/DOWN CLICK 移动、OK CLICK 进入(返回 enter 动作)、OK LONG 取消关闭、
RELEASE 透传(无连调语义)。固定 6 行无 hidden 无 editing — 不复用 modal_ctl
(其 OK=切编辑态语义不匹配)。

**UI**: stats 弹窗同款行样式, 6×40+57 = 297px 一屏装下(视口 304), 无需滚动。
行清单:

| 行 | 动作 |
| --- | --- |
| 听声辨机 | 开 Quiz 模式选择页 |
| 场景连播 | 开场景列表页 |
| 闹钟 | 开闹钟设置页 |
| 播放统计 | 开现有 stats 弹窗(从设置弹窗迁出) |
| 设置 | 开现有设置弹窗 |
| 硬件诊断 | 开诊断页 |

**交互改动**:

- OK 长按(主界面): 开设置弹窗 → **开主菜单**。
- 设置弹窗回归纯 4 行(音量/连播/随机/聆听), 高度 4×40+57 = 217px; 移除统计行
  与 MODAL_ITEM_STATS(矩阵/测试同步)。
- 主菜单交互与设置弹窗一致: UP/DOWN 选行、OK 进、OK 长按退、15s 闲置自动关、
  打开时停连发(沿用 modal_open 语义, 37b7ecd)。
- 弹窗互斥链不变: 一次只开一个(主菜单/设置/统计/诊断/Quiz 各页/闹钟页/场景页
  互斥), 旧弹窗先关再开新页。

## 3. 听声辨机 Quiz

### 3.1 模式与流程

主菜单「听声辨机」→ 模式选择页(2 行: **10 题挑战** / **无尽模式**) → 开始 →
答题 → 结算(挑战)或答错即止结算(无尽)。任意时刻 OK 长按退出回主菜单。

### 3.2 出题逻辑(quiz_ctl.h 纯状态机, host 测试核心)

- 题型 8:2 随机 — **听音题**(自动播一条警告音, 三选一猜名) / **场景题**
  (显示场景句, 三选一猜对应警告音名; 不播音)。
- 出题: 随机正确条目 + 2 个干扰项。**干扰项优先同 en 类别**{PULL UP 系
  (呼啸拉升/波音拉升/拉升警告), RETARD 系(减速连呼/减速提醒), STALL 系
  (失速警告/空客失速), TRAFFIC 系(冲突警告/空客冲突)}: 类别内有 ≥3 条时全从
  类别抽(难), 否则 1 同类 + 1 全库随机(避免同 en 撞名干扰)。
- 选项顺序随机。连续两题不重复同一条目(无尽模式 24 条环洗牌)。
- 判定: 答对 streak+1、800ms 后下一题; 答错 streak 归 0、红闪 + 播正确答案
  音、1.5s 后下一题(挑战)或结算(无尽)。
- 听音题出题自动播一次, 无重播手势(YAGNI: 音源 1.2~10s 播一次足够, 答错有
  正确音回放)。

### 3.4 UI 与交互

全屏遮罩弹窗(modal 样式): 题面区(听音题显示「▶ 第 N 题」+ 波形图标; 场景题
显示场景句) + 三个选项行 + 底部 hint「上中下键选择」。**三键直接 = 三选项
一步确认**(UP=上项/OK=中项/DOWN=下项), 零导航状态。答对选项高亮绿 800ms;
答错所选红闪 + 正确项绿亮。

### 3.5 计分与纪录

- 挑战: 10 题后结算(答对数/最长连对); 无尽: 答错即止, 连对数即成绩。
- NVS: `quiz_best_round`(挑战最佳答对数)、`quiz_best_streak`(无尽最佳连对),
  结算页显示「最佳」, 破纪录时结算页标注「新纪录」。

## 4. GPWS 闹钟

### 4.1 设置页(主菜单「闹钟」)

modal 编辑模式复用, 两行:

- **时长**: 1~120 分钟, 默认 5; 单击 ±1、长按连调(复用音量连调 repeat 基础设施)。
- **选曲**: UP/DOWN 在 24 条内循环显示曲名, 默认 0(呼啸拉升)。

OK 确认 → 显示「闹钟已设 N 分钟」短确认(1s) → 关机动画 → 深睡。

### 4.2 深睡与唤醒

- app_sleep 扩展: 闹钟深睡与闲置深睡共用序列, 唤醒武装改为
  `esp_sleep_enable_timer_wakeup(N 分钟)` **+ GPIO 唤醒并存**。
- boot_diag 记录唤醒源(wc uint8 天然兼容 TIMER=4); 站点(site)新增闹钟武装值。
- **GPIO 唤醒(按键) = 取消闹钟**: 走现有正常唤醒路径(key_guard arm 照常)。
- **TIMER 唤醒 = 响铃**: 新唤醒分支, 不 arm key_guard(无按键按住)。

### 4.3 响铃态

- 亮屏响铃页: 曲名 + 音波动画 + 「任意键停止」。
- 音频层新增 play 命令 loop 位(**单曲循环**, ~20 行): 播完自动重播。
- 任意键 → 停止循环 → 回主界面(正常亮屏态)。
- 低电兜底: 响铃中 lowbatt_poll 照常(≤5% 强睡, 真闹钟语义); 闲置熄屏/深睡
  计时对响铃态不适用(响铃页视为活跃会话)。

## 5. 硬件诊断页

stats 弹窗同款只读滚动列表(打开时快照, 不实时轮询), UP/DOWN 滚动, OK 返回。

### 5.1 重启历史环形日志(8 条)

boot_diag 改造: NVS blob `hist` = u8 写指针 + 8 × {rr, wc, site, run_min}
(33B), 每次启动追加一条; 弃用旧键 rr/wc/ps/rs。诊断页自上而下显示 8 条
(新→旧, 空槽显示「—」): `POWERON 唤醒源0 站点0 运行12分` 格式。

### 5.2 电池与 I2C 快照

- 打开时读一次: 电压 mV / SOC% / CW2017 版本号(bsp_battery 导出诊断快照
  API ~30 行)。
- I2C 设备表: 显示**冷启动扫描缓存**(bsp_i2c 缓存结果, 零打开等待;
  不做页内实时扫 — 最坏 5.6s 卡 UI)。冷启动扫描早退(总线卡死)时显示「扫描中止」。

### 6.2 播放机制

- 主菜单「场景连播」→ 场景列表页(行 = 场景名 + 条数, stats 版式) → OK 开始
  → 关弹窗回宫格, **复用连播视觉跟随**(ui_focus_jump/seq 机制现成) →
  **播完自动停**(序列尾不循环)。
- 音频层新增场景序列源(~40 行): 播完按序列下一条; 与 autoplay 开关无关
  (独立序列源, 不污染连播设置)。
- 现有交互全兼容: 播放中 OK 单击 = 暂停/继续; OK 双击 = 关屏(聆听+场景 =
  黑屏按序播, 语义自然); 切条目/停止照旧。

## 7. 跨功能边界

- 全部新页进 `app_ui_input` 消费链, 弹窗互斥规则照旧(一次一个)。
- 闹钟深睡与闲置深睡互斥(先到者执行): 闹钟确认即深睡(timer+GPIO 武装),
  闹钟态不存在亮屏闲置计时; 反之闲置深睡(GPIO-only 武装)不保留闹钟 —
  闹钟只在确认后有效, 深睡唤醒即清(重启语义, 见 app_sleep.h 惯例)。
- 场景播放与 Quiz 播音互斥(一次只播一条/一个序列); 进 Quiz 前停场景, 反之亦然。
- 主菜单打开时停连发(37b7ecd 语义沿用); 所有新页打开/关闭对称停连发。
- 计数/统计: Quiz 播音与场景播放**计入**播放统计(同一 app_audio 命令通道,
  计数语义一致)。

## 9. 实现批次

1. **主菜单底座**: menu_ctl + 主菜单 UI + OK 长按改道 + 统计迁移 + 设置回归 4 行。
2. **硬件诊断页**(服务即期电池调查): 环形日志 + 诊断快照 API + 页面。
3. **听声辨机**: quiz_ctl + 文案表 + 模式页 + 答题页 + 结算 + NVS 纪录。
4. **场景连播**: scenes.h + 音频序列源 + 场景列表页。
5. **GPWS 闹钟**: 闹钟页 + 双唤醒源深睡 + TIMER 唤醒响铃态 + 单曲循环。

每批独立过静态门禁 + 固件构建 + 真机验证 + 独立提交。
